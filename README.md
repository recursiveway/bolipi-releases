# bolipi releases

Downloads for **bolipi**, offline voice typing for Mac (Apple Silicon, macOS 13 or later).

**Latest version:** [bolipi.dmg](https://github.com/recursiveway/bolipi-releases/releases/latest/download/bolipi.dmg)
· website: https://bolipi-landing.vercel.app

Each release has `bolipi.dmg` (signed with a Developer ID and notarized by Apple) and
`bolipi.dmg.sha256`. This repository holds downloads only; it has no source code.
